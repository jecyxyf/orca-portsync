# orca-portsync

PortSync 为 Orca 的远程工作区转发项目的 TCP 端口。它支持桌面直连 SSH 工作区，以及通过 SSH 配对、已连接的 Orca 环境。

## 使用

1. 在 Orca 1.4.261 或更新版本的「设置 → 插件 → 开发目录」中添加本仓库，检查权限并启用。
2. 在 Orca 右侧打开 **PortSync**，选择远程工作区。直连 SSH 工作区需要在「SSH 连接设置」中保存本机 OpenSSH 别名。
3. **自动嗅探**。勾选「自动嗅探并转发」并保存。面板会列出发现的项目端口和转发后的本机地址。自动转发优先使用同号端口，冲突时选择其他空闲端口，服务停止后撤销。
4. **手动转发**。输入远端端口和本机端口后，点击「添加转发」。远端默认连到 `127.0.0.1`。本机端口被占用时，规则保留你填写的端口并显示冲突。手动规则可独立使用或删除。

配对环境由 Orca 命令行检测端口。在 Linux 桌面上，插件可以读取 Orca 保存的 SSH 目标地址来发起转发，设置里也可以填写可用的 OpenSSH 别名。直连工作区通过远端 Linux 的 `ss` 和进程工作目录识别项目端口。

实际转发使用插件自己的后台 OpenSSH 连接，需要本机能免交互登录且远端允许 SSH TCP 转发。首次连接可用本机的 `ssh <别名>` 确认主机指纹和认证。映射只在本机 `127.0.0.1` 监听。网页可以点击地址打开，其他 TCP 客户端可直接使用面板显示的端口。

## 验证

```sh
orca plugin validate . --json
orca plugin test . --json
orca plugin check . --json
```
